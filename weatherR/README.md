# weatherR

Мини-приложение Telegram: погода в Щецине и в радиусе 50 км. На карте Щецин, Полице, Голенюв, Грыфино и Старгард. Данные берёт Open-Meteo, ключ не нужен.

## Запуск

```bash
cd weatherR
python3 bot.py
```

Откройте http://127.0.0.1:8080

Нужен Python 3, отдельные пакеты не ставятся. Токен бота лежит в `.env` и в git не попадает.

Команды бота: `/start` и `/weather`.

## Адрес в Telegram

На телефоне бот открывает приложение только по ссылке, которая начинается с `https://`. Адрес `http://127.0.0.1:8080` работает в браузере на этом компьютере, в Telegram нет.

1. Запустите туннель на порт 8080 и скопируйте ссылку `https://…`.
2. Вставьте её в `WEBAPP_URL` в файле `.env`.
3. Снова запустите `python3 bot.py`.
4. Откройте бота и нажмите кнопку **weatherR**.
