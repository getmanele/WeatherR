# weatherR

Мини-приложение Telegram: погода в Щецине и в радиусе 50 км. На карте Щецин, Полице, Голенюв, Грыфино и Старгард. Данные берёт Open-Meteo, ключ не нужен.

## Запуск

```bash
cd weatherR
python3 bot.py
```

Откройте http://127.0.0.1:8080

Нужен Python 3, отдельные пакеты не ставятся. Токен бота лежит в `.env` и в git не попадает.

Команды бота: `/start` и `/weather`.

## В телефоне

На компьютере откройте http://127.0.0.1:8080

Телефон этот адрес не видит. Нужна ссылка `https://`. Впишите её в файл `.env` в строку `WEBAPP_URL` и запустите бота ещё раз. В чате нажмите **weatherR**.
