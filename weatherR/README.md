# weatherR

Мини-приложение Telegram: погода в Щецине и в радиусе 50 км. На карте Щецин, Полице, Голенюв, Грыфино, Старгард, а за кольцом Хощно и Хмельницкий. Погода — среднее из Open-Meteo, MET Norway, Bright Sky (DWD) и IMGW. Ключи не нужны.

## Стек

| Слой | Чем сделано |
| --- | --- |
| Бот и HTTP | Python 3, стандартная библиотека (`http.server`, `urllib`, `threading`, `sqlite3`). Отдельные pip-пакеты не ставятся. |
| Точка входа | `bot.py` — опрос Telegram (`getUpdates`), раздача `public/`, API `/api/point` и `/api/stats`, фоновый сигнал дождя. |
| Погода | `sources/compare.py` — среднее по Open-Meteo, MET Norway, Bright Sky (DWD), IMGW. |
| Mini App | Ванильные `public/index.html`, `app.js`, `styles.css`; SDK `telegram-web-app.js`. |
| Языки | `public/translate/` — ru, en, pl, uk, de. |
| Данные | SQLite `data/users.sqlite` (в git не кладём); профили в `data/users/…/profile.json`. |
| Секреты | `BOT_TOKEN` в `.env` (образец `.env.example`). |
| HTTPS для Telegram | Quick Tunnel **cloudflared** → `https://….trycloudflare.com`. Скрипты `./start.sh` / `./stop.sh`. Бесплатный ngrok для Mini App не подходит. |

## Запуск на Маке (Telegram Mini App)

Бот и страница приложения крутятся на этом компьютере. Telegram на телефоне их не видит по `localhost`, поэтому нужен временный HTTPS-туннель **cloudflared** (это не часть языка Python — туннель к порту 8080).

### Что нужно один раз

- Python 3
- `cloudflared` — если нет: `brew install cloudflared`
- файл `weatherR/.env` с токеном (в git не кладём):

```bash
BOT_TOKEN=...ваш_токен...
PORT=8080
WEBAPP_URL=http://127.0.0.1:8080
```

`WEBAPP_URL` при каждом `./start.sh` перезапишется на новый `https://….trycloudflare.com`.

Бесплатный ngrok для Mini App не использовать: в Telegram часто пустой экран.

### Запуск

Откройте **Terminal** и выполните:

```bash
cd ~/Documents/Frontend/telegram_bot/Cursor/GEO/Без\ названия/weatherR
./start.sh
```

Дождитесь строк вроде:

- `Туннель: https://….trycloudflare.com`
- `Бот @WeatherTest2010_bot`
- `Мини-приложение: https://…`

Окно Terminal **не закрывайте** и не жмите `Ctrl+C`, пока пользуетесь ботом. Работает только **один** `./start.sh` (два сразу дают конфликт опроса Telegram `HTTP 409`). Если порт 8080 был занят старым запуском, скрипт попробует остановить его сам.

Проверка на Маке (должно быть `200`):

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/
```

### Открыть в Telegram

1. Бот: **@WeatherTest2010_bot**
2. Откройте приложение **синей кнопкой weatherR** слева от поля ввода.
3. Внизу чата кнопки «Открыть weatherR» больше нет — так и задумано. Команда **/help** остаётся.
4. Не открывайте приложение из **старых** сообщений и старых ссылок: после каждого запуска адрес туннеля новый. Старый `https://….trycloudflare.com` даёт **502 Bad gateway / Host Error**.

### Остановка

В том же окне, где крутится `./start.sh`:

```text
Ctrl+C
```

Или в другом окне Terminal:

```bash
cd ~/Documents/Frontend/telegram_bot/Cursor/GEO/Без\ названия/weatherR
./stop.sh
```

После остановки Mini App в Telegram снова не откроется, пока не сделаете новый `./start.sh`.

### Только браузер на этом Маке (без Telegram)

```bash
cd ~/Documents/Frontend/telegram_bot/Cursor/GEO/Без\ названия/weatherR
python3 bot.py
```

Откройте http://127.0.0.1:8080 — телефон и Telegram этот адрес не видят.

Команды бота в чате: `/start` и `/help`.

## Версия 0.11

Снимок от 25 октября 2026. Архив `weatherR_v011` — запасная копия перед следующими правками. В него входят и локальные изменения, которые ещё не лежат отдельным коммитом в git.

В чате бота:

- синяя кнопка **weatherR** и кнопка **«Открыть weatherR»** открывают приложение;
- рядом только кнопка `/help`;
- кнопок выбора языка в чате нет.

В приложении:

- фон `#081710`, карта на SVG;
- кольцо 50 км крупнее, Хощно и Хмельницкий стоят по бокам, список точек внизу;
- «Моё место» остаётся первым, остальные точки сортируются по удалению от него;
- направление ветра на карте идёт от ветра в Щецине;
- после сохранения места кнопка «Моё местоположение» скрывается, вместо неё **GEO+**;
- если точка в еврозоне, подписывается страна;
- язык по-прежнему выбирается в приложении: из ссылки, из памяти телефона, из языка Telegram или с экрана выбора. Языки: русский, английский, польский, украинский, немецкий.

Погода и сигнал:

- температура и ветер — среднее ответивших источников, направление ветра считается по кругу;
- дождь смотрится с шагом 15 минут;
- предупреждение «через ~5 мин дождь» приходит один раз на дождь: сообщением в чат и строкой в приложении.

В архиве нет `.env`: токен остаётся только на этом компьютере. База пользователей `data/users.sqlite` в архив входит. Файлы профиля в папках пользователей в архив не входят.

## Версия 0.12

Снимок от 25 октября 2026. Архив `backUp/weatherR_v012.zip`. Справка `/help` описывает этот экран на пяти языках.

Карта:

- кольцо 50 км стремится к 90% ширины и уступает высоту, чтобы в списке было видно около трёх точек;
- подписи внутри кольца не наезжают друг на друга, от названия к точке идёт тусклая линия;
- строка о дожде на карте есть только если дождь уже идёт или начнётся в ближайшие 5 минут;
- штрихи ветра берутся из ветра выбранной точки, а не только из Щецина.

За кольцом и список:

- Хощно и Хмельницкий — только название, столбиком под кольцом, на стороне от места пользователя;
- в строке списка средний ветер и порыв;
- выбор точки прокруткой или нажатием подсвечивает строку и меняет ветер на карте.

Низ экрана:

- `weatherR` и «Щецин ± 50 км» в одной строке;
- сводка выбранной точки видна целиком и крупнее, под ней кнопки: дождь, средний ветер, порыв, влажность;
- блок «центр / кольцо / точки» называется footer и стоит за нижним краем экрана.

Погода:

- к среднему добавлены порыв и влажность. Порыв считают источники, которые его отдают. Влажность включает IMGW, если станция её прислала.

В архиве нет `.env` и папок профиля. База `data/users.sqlite` входит.

Приложение:
