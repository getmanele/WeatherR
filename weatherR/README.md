# weatherR

Мини-приложение Telegram: погода в Щецине и в радиусе 50 км. На карте Щецин, Полице, Голенюв, Грыфино и Старгард. Данные берёт Open-Meteo, ключ не нужен.

## Запуск

```bash
cd weatherR
python3 bot.py
```

Откройте http://127.0.0.1:8080

Нужен Python 3, отдельные пакеты не ставятся. Токен бота лежит в `.env` и в git не попадает.

Команды бота: `/start` и `/weather`.

## Адрес в Telegram

Telegram открывает мини-приложение только по HTTPS. Локальный `http://127.0.0.1` в чате не запустится.

1. Поднимите туннель на порт 8080 (ngrok или cloudflared) и возьмите выданный `https://…` адрес.
2. Запишите его в `WEBAPP_URL` в файле `.env` и перезапустите `python3 bot.py`.
3. В BotFather откройте бота → Mini Apps и создайте приложение weatherR с этим HTTPS-адресом. Либо после перезапуска нажмите кнопку меню `weatherR` в чате с ботом: бот ставит её сам, когда `WEBAPP_URL` начинается с `https://`.
